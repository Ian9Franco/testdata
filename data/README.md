# Data

`glacier_ops.sqlite` is generated, deterministic, and fictional. Rebuild it with:

```bash
python3 -m ops_lab.generate
```

Every timestamp in the lab is Pacific Time on purpose, so the exercise is about the operating process. Grand Rapids and Indianapolis are Eastern in real life; that conversion is called out in `docs/guia_es.md` and is not modeled in the tables. One scanner still carries a bad local label, and the daily pack shows how to catch it.
