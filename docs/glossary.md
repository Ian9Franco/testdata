# Glosario

| Término | Qué es |
| --- | --- |
| MRF | Materials recovery facility. La planta que separa el reciclable. |
| Infeed | Donde el material entra a esa línea, antes del robot. |
| Downstream | Después del robot. Si el infeed ve un pico y el downstream no, el robot alcanzó a sacar parte. |
| Residue | Lo que queda cuando el resto de la planta ya clasificó. Ahí aparece lo que se está perdiendo. |
| PET | Botellas de plástico tipo botella de gaseosa. |
| HDPE | Plástico rígido, por ejemplo bidones. |
| AL | Latas de aluminio. |
| OCC | Old corrugated cardboard. En una línea de fibra es el producto que hay que cuidar, no un contaminante. |
| Film | Film plástico. En este lab no es un target de los robots. |
| Burden | Cuántos objetos se ven en el cuadro. Bajo 8, la tasa de pick no se juzga. |
| Pick success | Aciertos sobre intentos, solo en commodities target. Un agarre de OCC en la línea de fibra no es un acierto. |
| Off-target | El brazo agarró algo que no debía. |
| E-stop | Parada de emergencia. No se puentea por teléfono. |
| Uptime | Tiempo programado en el que el robot podía trabajar. La noche cerrada no cuenta a favor. |
| CAT | Customer acceptance testing. La ventana en la que el cliente firma, asset por asset. |
| Leakage | Material con valor que aparece donde no debería, en general en el residuo. |
| 22 g | Supuesto de trabajo para estimar masa de un PET detectado. Se escribe en la oración. No es una balanza. |
